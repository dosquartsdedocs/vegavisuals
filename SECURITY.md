# Security Policy

## Supported Versions

Only the latest `0.2.x` release receives security fixes. Older and unreleased
development snapshots are not supported.

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| Earlier versions | No |

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory form:

<https://github.com/dosquartsdedocs/vegavisuals/security/advisories/new>

Include the affected version, operating system, Docker version, reproduction
steps, impact, and any proposed mitigation. Reports about path confinement,
renderer isolation, output validation, conditional publication, rollback, MCP
input handling, or dependency integrity are in scope.

The maintainers will acknowledge a complete report as soon as practical,
coordinate validation and remediation privately, and publish credit when the
reporter requests it.
